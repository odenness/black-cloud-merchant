# Black Cloud Pet Ledger

Quick reference for AION 2: which pets are **shop-only** (their soul never drops from a monster), so you know what to grab when the Black Cloud Merchant has it.

- 35 shop-only pets out of 200, grouped by genus, with icons
- Search any pet name you see in the shop to get **Buy it** or **Skip** (with where it drops)
- Tap a pet to mark it owned (saved in your browser)

Static site — no build step. Push to GitHub and enable Pages on the root of the default branch.

Data and icons: [aion2.th.gl](https://aion2.th.gl/db/pets). `data.js` flags `x:1` when the pet's soul item has no "Dropped by" source.
